# Interaction and visual system

Persistent project/model/variant/applied-revision header, three workspaces and explicit saved/draft status remain authoritative. Primary project commands stay visible; secondary tools share a menu and Vista exposes the component navigator. Ctrl1/2/3 select Modelo/Simular/Resultados; CtrlShiftM components, CtrlShiftR runs, CtrlShiftD exact variant differences, CtrlShiftO recovery selector. Native field units retain case. Selected components use a checked native button and a focus border, not colour alone.

Topological diagrams route to the existing physical editors.2T intake routes to crankcase/transfer/ports;4T intake and exhaust route through their valves. No scale, dimensional CAD, animation or new physical calculations are claimed. Applied dimensions are separate from editor drafts. Advanced schemas, diagnostics and provenance remain available.

Chart tools share plus/minus/reset, exact-sample readout, original sample table, CSV and PNG. Left/right traverse finite source samples, middle drag pans and wheel zooms at the pointer. Missing values remain empty in CSV with reason/status and original metadata; native RPM sweeps never join forbidden points. A/B pressure overlay requires the existing full eligibility contract and re-verifies both primary snapshots, including origin qualifications. No resampling or synthetic measurement claim.

Native A/B metrics and pressure use tabs; report exports use a two-column layout. Component dock is explicitly opened so compact windows retain editor width. Native widgets supply focus and accessible names; screen-reader/high-contrast/scaling acceptance remains human UAT, never inferred from programmatic labels.

Recovery previews read serialized data without running models. Posponer never discards. Open is a copy without an original path; save therefore requires SaveAs. Deferred entries remain available after restart.


Visual QA led to an explicit expanded-chart window using the same renderer and frozen received samples. Its cursor can update the original selection only while source samples still match. Embedded charts retain scroll support; the expanded view supplies sufficient room for axes, exact values and units. Applied component details scroll independently, without hiding model limits. Secondary toolbar actions are kept in the menu after family switches. Recovery validates the incoming document before any discard prompt and guards the destination model, including an inactive context; Cancel preserves both project and prior active family.
