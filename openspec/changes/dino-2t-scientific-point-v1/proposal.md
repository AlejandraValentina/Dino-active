# DINO 2T Scientific Point V1

Prepare a reproducible, auditable single operating-point verification using the integrated 2T solver. Close demonstrated software and geometry defects, measure bounded performance, verify periodicity reporting and conservation, and prepare mesh-refinement and point preflights. A real operating-point run requires an explicit, hash-bound execution authorization and bounded time/memory/cycle limits; this change does not by itself authorize an expensive run.

Historical Recovery V1/V2, IMPL2 preregistration, exhausted checkpoints, RPM campaigns, and desktop behavior remain immutable. No RPM sweep or mesh-independence claim is in scope.
