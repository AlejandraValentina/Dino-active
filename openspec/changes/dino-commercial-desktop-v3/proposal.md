# DINO_COMMERCIAL_DESKTOP_V3

## Why

The existing Qt workbench has capable engineering editors and honest result semantics, but its fixed results panel, inconsistent native Windows styling, duplicated execution controls and dense technical views prevent a natural commercial-style workflow. The owner supplied an independent visual review and six data-based mockups for the exact baseline HEAD.

## Scope

Restructure the existing desktop into persistent DISEÑO and ANÁLISIS modes; correct P0 defects; complete the motor, distribution, exhaust, simulation, wave, comparison and responsive workflows using existing configuration, run, audit and plotting APIs. Add focused automated regressions and verify real Windows and packaged behavior when the desktop is available. Preserve actual data, audit and undefined-result semantics.

## Non-goals

- Any solver, physics, mesh adapter, hard gate, convergence criterion, artifact, historical receipt or result change.
- New diagnostics, simulations, campaigns, RPM queues, VERIFIED activation or empirical performance estimates.
- Inverse timing controls, drag geometry, undo/redo, empirical recommendations or other separately identified P3 capabilities.
- Automatic transition to another development phase after this objective.
