# EXHAUST_NUMERICAL_CONVERGENCE_V2

Determine whether the existing quasi-1D exhaust solver has controlled wave behavior and spatial convergence, and whether the measured A/B design difference is distinguishable from discretization error. The current final mesh adapter has a new hash relative to earlier diagnostics, so all new evidence is tied to the current source identity.

This work is diagnostic only. It does not authorize a full RPM sweep, KT100, periodicity claims, experimental validation, or changes to frozen historical evidence. New solver diagnostics have an aggregate wall budget of 1800 seconds.
