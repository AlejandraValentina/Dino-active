# Reference engine hybrid harness

Create a reusable campaign harness for configurable reference-engine cases,
separate from historical P4–P9 campaign contracts. It orchestrates existing
P5-C gas topology, P6 species, P7 prescribed-source, CFL/Riemann and checkpoint
capabilities; it adds configuration, cycle-relative event scheduling, a
separately named periodic-convergence contract, primary evidence and an
independent offline auditor. The first client is KT100 V2, with explicit
synthetic completion and no Yamaha performance claim.
