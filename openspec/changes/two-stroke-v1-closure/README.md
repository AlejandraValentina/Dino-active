# two-stroke-v1-closure

## Why

The current synthetic integrated fixtures cannot support a general-purpose 2T v1 claim: they start under invalid pressure/boundary conditions and use prescribed bookkeeping heat instead of fuel-limited combustion. This change establishes the versioned OpenSpec definition of done for two new preregistered prime fixtures and their offline-auditable evidence.

## What changes

It closes the critical path from endpoint equilibrium and integrated atmospheric boundaries through topology, fuel-coupled combustion, scavenging/performance outputs, primary evidence, restart/replay, mesh sufficiency, and fixed-horizon A'/B' verification. It explicitly keeps historical A/B/C evidence, P7, P4-P9 contracts, KT100, and deferred product capabilities separate.

## Capabilities

- `two-stroke-v1-closure`: auditable synthetic single-cylinder 2T v1 core gate.
