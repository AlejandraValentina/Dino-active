# Caso de referencia Yamaha KT100

Crear un caso documental `KT100_REFERENCE_CASE_V1` para la variante Yamaha
KT100SP identificada en la fuente oficial de 1998 y separarlo de un fixture
ejecutable `KT100_MODEL_FIXTURE_V1` completado con supuestos sintéticos
trazables. El alcance V1 y sus resultados se conservan sin reinterpretación.

La continuación autorizada estudia `KT100_HYBRID_MODEL_FIXTURE_V2` con P5-C,
P6, P7, P8 y E13 existentes. No cambia P4–P9 ni la referencia Yamaha. La
investigación encontró que el stack actual no expone un productor y auditor P8
parametrizables para esta geometría y periodicidad multicíclo con P7; por ello
V2 queda bloqueado antes de campaña, sin claim de fixture verificado.
