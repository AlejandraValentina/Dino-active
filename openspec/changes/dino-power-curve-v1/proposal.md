# DINO_POWER_CURVE_V1

Add a usable RPM performance curve workflow to the existing Dino Desktop: load
existing validated RPM results, display brake power and torque against RPM,
compare compatible configurations at exact common RPM values, and execute a
bounded exploratory sweep by reusing the integrated engine runner.

The work does not change physics, solver equations, historical identities, or
scientific acceptance criteria. A configured sweep is not campaign
authorization. Real runs require an explicit in-app confirmation of their
scope and budget.
