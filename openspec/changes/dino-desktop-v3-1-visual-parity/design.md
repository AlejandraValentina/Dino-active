# Diseño

Usar los widgets y servicios actuales como fuente de verdad. Cambiar únicamente composición, presentación y flujo de trabajo de Qt. Las vistas geométricas derivan datos del proyecto; no se crea un modelo inverso ni una interpolación de resultados. Reubicar los mismos controles de ejecución en un panel contextual y conservar un solo estado. Las corridas se siguen cargando/auditando con el pipeline actual. El artifact root inseguro se rechaza antes de crear/escribir nuevos artifacts.

La aceptación visual requiere capturas del paquete TRIAL para los seis estados. La falta de una capacidad del backend se muestra explícitamente, nunca mediante datos simulados.
